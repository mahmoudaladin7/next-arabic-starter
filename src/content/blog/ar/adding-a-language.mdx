التوجيه ومبدّل اللغة وروابط hreflang وخريطة الموقع، كلها تقرأ من قائمة واحدة للغات. إضافة لغة تعني إضافتها إلى هذه القائمة وترجمة محتواك.

## 1. سجّل اللغة

افتح `src/i18n/routing.ts` وأضف رمز اللغة إلى `locales`، ثم أضف سطرًا لها في `localeMeta`:

```ts
export const routing = defineRouting({
  locales: ["ar", "en", "ur"],
  defaultLocale: "ar",
  localePrefix: "always",
});

export const localeMeta = {
  ar: { dir: "rtl", nativeName: "العربية", ogLocale: "ar_SA" },
  en: { dir: "ltr", nativeName: "English", ogLocale: "en_US" },
  ur: { dir: "rtl", nativeName: "اردو", ogLocale: "ur_PK" },
};
```

الخاصية `dir` هي الوحيدة التي تغيّر التخطيط. اجعلها `"rtl"` للعربية والأردية والفارسية والعبرية.

## 2. ترجم الرسائل

انسخ `messages/en.json` إلى `messages/ur.json` وترجم القيم مع إبقاء المفاتيح كما هي. ثم شغّل:

```bash
npm run check:i18n
```

سيعرض لك أي مفتاح ناقص أو زائد في الملف الجديد.

## 3. أضف المقالات

أنشئ المجلد `src/content/blog/ur/` وأضف المقالات بأسماء الملفات نفسها المستخدمة في اللغات الأخرى، ليتمكن المبدّل من الربط بين الترجمات.

## 4. راجع الخطوط

إذا كانت اللغة الجديدة تُكتب بحروف لا تغطيها خطوطك، فأضف خطًا لها في `src/lib/fonts.ts`. الأردية مثلًا تُقرأ عادة بشكل أفضل بخط النستعليق. أما اللغات المكتوبة بالحروف اللاتينية أو العربية فتعمل مع الخطوط المرفقة.

هذا كل شيء. ستظهر اللغة الجديدة في المبدّل وخريطة الموقع وروابط hreflang دون أي تعديل آخر.
